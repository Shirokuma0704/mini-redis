# 캐시 효과 측정 결과

샘플 앱을 캐시 끈 채로, 켠 채로 진짜 HTTP로 돌려 요청 지연을 비교했다. `python -m bench.cache_effect`가 이 파일을 다시 만든다.

- 컴퓨터: Windows-11-10.0.26200-SP0, Intel64 Family 6 Model 197 Stepping 2, GenuineIntel, CPU 14개, Python 3.14.7
- 아이템 100개, 이후 요청 2000개, 동시 요청 16개, 반복 3회 (시드 18)
- 가짜 원본 지연 200ms, 샘플 캐시 TTL 60초
- 모드마다 프로세스 세 개를 새로 띄운다. 모든 반복의 행을 그대로 적는다(최솟값이나 평균을 내지 않는다).
- 비-200 응답은 에러 열에 센다. 요청 열은 성공한 요청 수다.
